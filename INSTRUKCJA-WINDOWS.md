# Sterownik Studio — szybki start

**Wymagania:** Windows 10 lub 11, 64-bit. Instalator zawiera potrzebne środowisko.

Po instalacji uruchom **Sterownik Studio** z menu Start lub pulpitu. Zamknięcie przeglądarki nie zatrzymuje kolejki. Ikona programu w zasobniku pozwala otworzyć panel, połączyć telefon, sprawdzić stan albo zakończyć program.

W panelu dodaj zdjęcia, wybierz obróbkę i sprawdź wynik przed zatwierdzeniem. Telefon łączy się wyłącznie przez adres pokazany po uwierzytelnieniu w opcji „Połącz telefon”.

Instalator nie jest podpisany cyfrowo — SmartScreen może pokazać ostrzeżenie. Weryfikuj plik sumą SHA-256 z `SHA256SUMS.txt`. Wydanie 1.8.0 jest pilotażowe.
